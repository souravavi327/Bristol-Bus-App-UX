# Bristol Bus Journey Planner: UX/UI Design Lifecycle

## Project Overview
This project was developed as part of the Digital Design and Development module at the University of the West of England (UWE Bristol). The objective was to research, wireframe, and design a user-centric web application prototype to solve real-world transit challenges for university students navigating the Bristol bus network.

## The Problem
Students frequently struggle with disjointed transit information, making it difficult to plan journeys, compare operator fares, and locate nearby stops in real-time between classes. 

## My Design & Systems Analysis Process
I managed the entire product design lifecycle from initial requirements gathering to high-fidelity interactive prototyping:

1. **Requirements & Personas:** Developed a core user persona ("Avi, a UWE Student") to anchor the design requirements around speed, mobile accessibility, and real-time mapping.
2. **Information Architecture:** Created UX journey maps and application blueprints to define the navigation flow (Home -> Map -> Fares -> Operators).
3. **Prototyping:** Designed low-fidelity wireframes, established a visual Mood Board (typography and colour theory), and developed high-fidelity UI mockups.
4. **Data Integration Strategy:** Leveraged Open Data Bristol (Traffic Survey Locations) and ArcGIS datasets to inform the geographic mapping features.

## Iterative User Testing & Agile Feedback
A critical component of this project was applying iterative improvements based on user testing, utilising the **"What, So What, Now What"** reflection model:

* **Spatial Awareness on Maps:** * *Feedback:* Users found it difficult to identify the absolute closest stop on the map.
  * *Action:* Logged a feature update to introduce distinct location pins and a "Nearest Stop" toggle to enhance UX accessibility.
* **UI Clarity vs. Aesthetics:**
  * *Feedback:* Some users requested more illustrations on the home page.
  * *Action:* Evaluated the feedback against the core persona's need for *speed*. Deliberately chose to maintain a minimalist, high-contrast design to ensure fast loading times and distraction-free usability.
